# Google Maps Lead Scraper

A Python project designed to automate the collection of business leads directly from Google Maps. 

## Features
- **Automated Browsing:** Leverages [Playwright](https://playwright.dev/python/) to launch a browser, perform searches, and scroll through listings natively.
- **Detailed Extraction:** Automatically pulls out the Business Name, Phone Number, Website URL, and Rating for each lead.
- **CSV Export:** Saves all the gathered data correctly formatted into a `leads.csv` file for easy import into Excel or CRM systems.
